# Protótipos de temas

Seis conceitos visuais gerados com a ferramenta integrada `image_gen`. Cada PNG apresenta a tela inicial e uma partida lado a lado, seguindo a hierarquia do aplicativo existente.

São imagens de protótipo. **Capivara na lagoa**, **Biblioteca encantada**, **Fundo do mar**, **Jardim das abelhas**, **Escola de magia** e **Refúgio na neve** estão implementados como opções do seletor **Temas**, junto do **Jardim do Gatinho**, com artes cartoon aprovadas. Escola de magia é o nome escolhido pelo usuário para a proposta originalmente chamada Oficina de magia. Consulte a [validação inicial](../temas/validacao.md) e os relatórios da [biblioteca](../temas/biblioteca-encantada.md), [fundo do mar](../temas/fundo-mar.md), [abelhas](../temas/jardim-abelhas.md), [escola de magia](../temas/escola-magia.md) e [refúgio na neve, versão 0.8.0+13](../temas/refugio-neve.md).
