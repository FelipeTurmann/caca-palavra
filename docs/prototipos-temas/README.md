# Protótipos de temas

Seis conceitos visuais gerados com a ferramenta integrada `image_gen`. Cada PNG apresenta a tela inicial e uma partida lado a lado, seguindo a hierarquia do aplicativo existente.

São imagens de protótipo; os temas não foram implementados no app.

- [Capivara na lagoa](01-capivara-na-lagoa.png)
- [Biblioteca encantada](02-biblioteca-encantada.png)
- [Fundo do mar](03-fundo-do-mar.png)
- [Jardim das abelhas](04-jardim-das-abelhas.png)
- [Oficina de magia](05-oficina-de-magia.png)
- [Refúgio na neve](06-refugio-na-neve.png)

Os prompts completos estão em [prompts.json](prompts.json). A imagem da capivara serviu de referência de composição para os outros cinco temas.
